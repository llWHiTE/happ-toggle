УСТАНОВКА
  Дважды щёлкните по com.llwhite.happtoggle.streamDeckPlugin.
  UUID действий не менялись, настройки существующих кнопок сохраняются.
  Happ → Happ VPN / Замер скорости (Speed Test в английском интерфейсе).
  Для Stream Deck+ перетащите «Замер скорости» на место крутилки.
  Для Stream Deck Neo перетащите это же действие на Infobar и добавьте
  обычную кнопку «Замер скорости» для запуска теста. Поддержка Infobar
  требует Stream Deck 7.6+; это минимум для всего пакета 1.12.
  Установленную копию плагин самостоятельно не обновляет.

КНОПКИ
  Happ VPN: короткое нажатие переключает VPN; удержание запускает тест скорости.
  Замер скорости: короткое нажатие запускает тест при отпускании; повторное
  нажатие во время теста отменяет его сразу. Удержание свободной кнопки
  переключает сервис: Yandex → Cloudflare → Speedtest.net → Yandex.
  Порог удержания по умолчанию 0.6 с (longPressMs в user-config.json).
  В ожидании на кнопке скорости видно название выбранного сервиса.

STREAM DECK+
  Вращение крутилки в любую сторону выбирает сервис замера, не запускает тест.
  Короткое нажатие крутилки запускает/отменяет тест при отпускании.
  Удержание крутилки (0.6 с по умолчанию) переключает Happ VPN;
  при отпускании после удержания тест не запускается. Вращение с зажатой
  крутилкой не выбирает сервис и не вызывает тест/VPN при отпускании.
  Короткое касание сенсорного экрана переключает Happ VPN.
  Экран показывает статус VPN, выбранный сервис, загрузку ↓ и отдачу ↑.
  Во время теста видны текущие измерения и этап; для Speedtest.net после
  завершения также показывается номер выбранного тестового сервера.
  Итог остаётся до следующего теста, смены сервиса или состояния VPN.
  Смена сервиса во время теста на этой крутилке отменяет тест и очищает цифры.
  Отдельная VPN-кнопка для опроса статуса крутилке не требуется.
  Выбор сервиса сохраняется отдельно для каждой кнопки/крутилки и не меняет
  настройки других контролов. Одновременно выполняется только один тест.

STREAM DECK NEO
  Infobar 232×50 показывает статус VPN, сервис замера и скорости ↓/↑.
  Замер запускается обычной кнопкой на том же устройстве Neo; экран отражает
  этапы, результат, отмену и ошибки. Замеры другого устройства сюда не выводятся.
  Infobar не принимает нажатия. Опрос VPN работает без отдельной VPN-кнопки.
  Итог остаётся независимо от времени показа на кнопке, до нового теста,
  смены сервиса кнопки-источника или состояния VPN. После перезапуска плагина
  цифры сбрасываются. Настройки языка и оформления Infobar — собственные.

ЧТО ОЗНАЧАЕТ СЕРВЕР И СКОРОСТЬ
  Выбирается сервис проверки скорости (Yandex / Cloudflare / Speedtest.net),
  а не VPN-сервер Happ. Текущий VPN-сервер и его переключение через используемый
  happ://toggle_without_ui недоступны. Плагин не выдаёт сервер замера за VPN-узел.
  Скорость — результат теста соединения, не непрерывный мониторинг трафика.

НАСТРОЙКИ
  Язык — русский или English для каждой кнопки/крутилки.
  Встроенные иконки прозрачные и без наружных рамок. Вместо VPN ON/OFF
  и ВКЛ/ВЫКЛ — символ питания: зелёный подключён, серый отключён,
  янтарный разорванный круг переключения, красный знак ошибки.
  Можно выбрать собственные картинки; пользовательские файлы не меняются.
  Сервис по умолчанию — Yandex. Старый OpenSpeedTest переводится на Yandex;
  явный выбор Cloudflare или Speedtest.net сохраняется.
  Формат кнопки «↓/↑ вместе»: цветные скорости на двух строках, отдельно единицы
  и ping. Обводка текста убрана, длинные числа уменьшаются автоматически.
  Пользовательская картинка приглушается только во время отображения цифр.
  «По этапам крупно» показывает символ и цифру текущего измерения.
  Названия latency/download/upload (задержка/загрузка/отдача) не выводятся.
  Время показа результата действует только для обычных кнопок.
  Галочка «До следующего замера» отключает таймер исчезновения результата
  (displaySec=0). Смена сервиса, маршрута или отмена очищают устаревшие цифры.
  Без галочки результат показывается заданное число секунд.
  У экранов Stream Deck+ и Neo своя разметка, без квадратных иконок;
  выбор «↓/↑ вместе» / «По этапам крупно» теперь доступен и для экранов.
  После завершения теста всегда показываются обе скорости.
  «Прозрачная подложка экрана» убирает заливку плагина, сохраняя яркость текста.
  Цвет/вид прозрачных областей определяет Stream Deck: наложение на другие
  системные виджеты не гарантируется. По умолчанию тёмная подложка сохранена.
  «Скрыть название сервиса/сервера замера» скрывает эту строку на обоих экранах.
  На кнопке скорости полностью убирается подпись, включая ТЕСТ/SPEED;
  спидометр увеличивается в 1.4 раза и центрируется, а не только сдвигается.
  На экранах без имени увеличивается символ статуса и область чисел.
  Настройки каждого контрола независимы.
  «Показывать задержку на экране» добавляет часы и значение ms на Stream Deck+
  или Neo; по умолчанию выключено. Используется HTTP-задержка того же теста,
  не ICMP ping. В Neo три компактные колонки ↓/↑/часы; в Stream Deck+ отдельная
  строка задержки. В режиме «По этапам» часы текущего ping не дублируются.

ОФОРМЛЕНИЕ СКОРОСТИ И АНИМАЦИИ
  «Формат скорости»: Мбит/с / МБ/с (Mbps / MB/s). Для МБ/с результат делится
  на 8 только при отображении; методика замера не меняется.
  «Показывать единицы скорости»: можно скрыть Мбит/с / МБ/с без скрытия цифр.
  Освободившееся место используется для увеличения/центрирования чисел.
  Измеряемая скорость всегда выводится во время теста и обновляется по мере
  получения данных (примерно раз в 0.5 с). До первой пробы видны прочерки,
  а не выдуманные нули. Это не непрерывный мониторинг текущего трафика.
  Точность всегда автоматическая; прежняя настройка удалена и игнорируется.
  «Шрифт цифр»: Segoe UI / Arial / Consolas / Bahnschrift. В SVG передаётся
  отдельное семейство вместо CSS-списка запасных шрифтов. Выбранный шрифт
  должен быть установлен в Windows; при отсутствии запасной выбирает рендерер.
  Различие шрифтов нужно проверить на устройстве.
  «Стиль цифр»: обычный / полужирный / жирный / курсив. Размер подбирается
  автоматически, обводка не используется. Подписи имеют интерфейсный шрифт.
  «Анимация теста скорости» и «Анимация простоя» включены по умолчанию;
  любую можно отключить отдельно. VPN-иконка очень плавно затухает и загорается
  по синусоиде за 6 секунд. Спидометр слегка двигает стрелку. Во время теста
  мягко движутся только символы направления или стрелка часов, не цифры.
  Статусная иконка экрана продолжает дышать и при сохранённом результате:
  прежний результат больше не блокирует анимацию простоя. Ошибка статична.
  Пользовательская VPN-картинка затухает целиком, исходный файл не меняется.
  Кадры обновляет один общий таймер 100 мс (до 10 кадров/с), только для видимых
  анимируемых контролов. Анимация не запускает дополнительные замеры/опросы.

НАДЁЖНОСТЬ ЗАМЕРА
  Yandex считает общие переданные байты за общий интервал параллельных потоков.
  Speedtest.net сравнивает задержку до четырёх кандидатов, проверяет загрузку
  и отдачу и считает общие байты за общий интервал, а не сумму пиков потоков.
  Cloudflare использует speed.cloudflare.com/__down и /__up. Пробы короче
  10 мс и неподтверждённые POST не участвуют в результате; ожидание HTTP-ответа
  входит во время пробы. Задержка измеряется после установки TLS/прокси,
  это HTTP-задержка, не ICMP ping. В лог пишется выбранный сервер.
  Плагин не использует официальный движок Ookla: результаты не обязаны
  совпадать с браузером. Низкий результат не масштабируется искусственно.
  Недостаток достоверных данных показывается как ошибка, а не нулевая скорость;
  при такой ошибке попробуйте длительность 10–15 секунд.
  curl.exe получает явный прокси Happ или явно отключает прокси для прямого
  маршрута; переменные среды и пользовательский .curlrc не меняют тест.
  При ошибке определения прокси тест отменяется, а не уходит на прямой маршрут.
  Ручной старт отменяет отложенный автозамер. Частые тесты расходуют трафик.

ПОВЕДЕНИЕ HAPP
  Если Happ был скрыт или свёрнут, после happ://toggle_without_ui плагин
  пытается вернуть прежнее состояние окна. Короткая вспышка окна возможна,
  потому что Windows/сам Happ обрабатывают deeplink раньше восстановления.

ДИАГНОСТИКА
  Поставляемый config.json неизменяем. Для своих настроек создайте
  %APPDATA%\HappToggle\com.llwhite.happtoggle\user-config.json — обычный JSON
  с нужными переопределениями: speedProxy («auto», «» или URL), speedServer
  (Cloudflare), speedStreams, признаки VPN и longPressMs. Лог plugin.log
  хранится в той же пользовательской папке. Не включайте её в публикацию.
  Не меняйте файлы защищённого Marketplace-плагина; старые ручные настройки
  config.json перенесите в отдельный user-config.json до обновления.
  При наличии Node.js и собранного SDK: node bin/plugin.js --diag;
  node bin/plugin.js --speed 3 --provider yandex (cloudflare/speedtest — альтернативы).

ПРОВЕРКА НА УСТРОЙСТВЕ
  Кнопка скорости: короткий запуск, отмена повторным нажатием, удержание для
  выбора сервиса; VPN-кнопка: удержание по-прежнему запускает тест.
  Крутилка: выбор в обе стороны, сохранение после перезапуска, запуск/отмена,
  короткий запуск и удержание для VPN без двойного действия, касание для VPN,
  статус без VPN-кнопки, прозрачность и скрытие имени сервиса.
  Neo: статус, запуск/отмена обычной кнопкой, сохранение итога после исчезновения
  цифр с кнопки и отсутствие замеров другого устройства.
  На кнопках и обоих экранах: полное скрытие имени без ТЕСТ/SPEED, скрытие
  единиц, Мбит/с против МБ/с (значение /8), шрифты и стили,
  два режима компоновки и обновление измерений во время теста.
  Отключение каждой анимации должно сразу прекращать её без остановки теста.
  Проверьте простой экрана после теста, рост иконки без имени, отсутствие
  рамок/VPN-подписей/названий этапов, задержку на обоих экранах, различие Arial
  и Consolas, а также галочку «До следующего замера» на кнопке скорости.
  Сравните результаты трёх сервисов с браузером через один маршрут в близкое
  время. Сетевое и аппаратное тестирование оставлено пользователю.

ENGLISH
  Speed Test key: short press starts a test on release, press again to cancel;
  hold an idle key to cycle Yandex / Cloudflare / Speedtest.net.
  Stream Deck+: rotate to select a test service, short press starts/cancels
  a test on release; hold the dial or tap the screen to toggle Happ VPN.
  Neo Infobar displays tests started by a key on the same device (Stream Deck
  7.6+ required). Place Speed Test both on Infobar and on a regular key.
  Hide test service/server name now removes the full key label, including
  TEST/SPEED. Speed settings apply to keys and both screens: Mbps/MB/s,
  optional unit labels, Segoe UI/Arial/Consolas/Bahnschrift and
  regular/semibold/bold/italic numbers. Rounding is now always automatic.
  Selected fonts use a single SVG family and must be installed in Windows.
  Icons have no outer frame or VPN text. Hiding the service enlarges the gauge.
  Show latency on the screen adds the test's HTTP delay, not ICMP ping.
  Until the next test keeps a key result without an expiry timer.
  Test and idle animations remain independently switchable and on by default.
  The VPN icon breathes smoothly over 6 seconds; the gauge needle moves gently.
  Screen idle animation also works with a retained result. Numbers do not blink.
  Measurements always update during the test; this is not live traffic.
  Screens also support the combined and large-by-phase layouts. Results remain until the
  next test, service or VPN state change. Each key/dial saves its own selection.
  These are speed-test services, not Happ VPN servers. The Happ VPN key still
  starts a test when held. Hardware and real-network testing is left to you.
